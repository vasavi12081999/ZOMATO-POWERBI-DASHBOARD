# ZOMATO-POWERBI-DASHBOARD
Interactive Zomato Restaurant Analytics Dashboard using Power BI
Developed a 3-page interactive Power BI dashboard to analyze restaurant ratings, pricing, cuisines, service availability, and geographic distribution.

Tools : Power BI, Power Query, DAX.

Features : KPI Cards, Interactive Slicers, Top 10 Analysis, Cuisine Analysis, Geographic Map, Drill-Down, Page Navigation.
